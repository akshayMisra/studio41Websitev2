STUDIO41

Connect the database

One-time setup, about 10 minutes. After this, pressing Save in the admin changes the live site straight away.

  1. Make a free Supabase project.

    Go to supabase.com/dashboard, choose Continue with GitHub, then New project. Name it “Studio41”, pick the region Southeast Asia (Singapore), and save the database password somewhere safe (the admin doesn’t need it).

  2. Create the admin account.

    In the project: Authentication → Users → Add user → Create new user. Email admin@studio41.tv, password PurplePeople, and tick Auto Confirm User. (No email is sent. To use a different email, also change adminEmail in studio41_live.js.)

  3. Turn off sign-ups so nobody else can make an account:

    Authentication → Sign In / Providers → switch off Allow new users to sign up → Save.

  4. Create the video tables.

    SQL Editor → New query, paste everything below (it’s also in studio41_supabase_setup.sql), then press Run.

    -- =====================================================================
--  STUDIO41 — database setup for the admin page
--  Run this ONCE in Supabase → SQL Editor → New query → Run,
--  AFTER you have created the admin user (Authentication → Users).
--  It is safe to run again (for example after adding another admin user).
-- =====================================================================

-- The video lists, one row per page (home, firsttake, originals, promos, live).
create table if not exists public.site_videos (
  page text primary key,
  data jsonb not null,
  updated_at timestamptz not null default now()
);

-- Every earlier version, so a save can be undone from the admin page.
create table if not exists public.site_videos_history (
  id bigint generated always as identity primary key,
  page text not null,
  data jsonb not null,
  saved_at timestamptz not null default now()
);

-- Who may change the videos: every user that exists when this is run.
create table if not exists public.site_admins (
  user_id uuid primary key references auth.users on delete cascade
);
insert into public.site_admins (user_id) select id from auth.users on conflict do nothing;

create or replace function public.is_site_admin() returns boolean
language sql stable security definer set search_path = public as $$
  select exists (select 1 from public.site_admins where user_id = auth.uid());
$$;

create or replace function public.keep_video_history() returns trigger
language plpgsql security definer set search_path = public as $$
begin
  insert into public.site_videos_history (page, data, saved_at) values (old.page, old.data, old.updated_at);
  return new;
end $$;
drop trigger if exists keep_video_history on public.site_videos;
create trigger keep_video_history before update on public.site_videos
  for each row execute function public.keep_video_history();

-- Everyone can read the videos; only admins can change them or see old versions.
alter table public.site_videos enable row level security;
alter table public.site_videos_history enable row level security;
alter table public.site_admins enable row level security;

drop policy if exists "Anyone can read the videos" on public.site_videos;
create policy "Anyone can read the videos" on public.site_videos for select using (true);
drop policy if exists "Admins can add pages" on public.site_videos;
create policy "Admins can add pages" on public.site_videos for insert to authenticated with check (public.is_site_admin());
drop policy if exists "Admins can change pages" on public.site_videos;
create policy "Admins can change pages" on public.site_videos for update to authenticated using (public.is_site_admin()) with check (public.is_site_admin());
drop policy if exists "Admins can see old versions" on public.site_videos_history;
create policy "Admins can see old versions" on public.site_videos_history for select to authenticated using (public.is_site_admin());

grant select on public.site_videos to anon, authenticated;
grant insert, update on public.site_videos to authenticated;
grant select on public.site_videos_history to authenticated;
  5. Connect the site to it.

    Project Settings → API Keys: copy the Project URL (under Data API) and the publishable key (or the legacy anon public key). Paste them at the top of studio41_live.js where it says PASTE-YOUR-SUPABASE-… (both are safe to be public).

  6. Upload studio41_live.js, this admin page and the five Studio41 pages to GitHub, then open this page on the site and sign in as Admin.
